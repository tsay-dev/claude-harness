# AGENTS.md — Codex entry for this repository

This repository's working guide for modifying the harness is [`CLAUDE.md`](./CLAUDE.md). **Read it before changing anything here.** The SSOT is `.claude/`. Conversation with the user is in Japanese; deliverables under `docs/` (and commit messages, in-code comments) are in Japanese.

- **Never hand-edit `.agents/` or `.codex/agents/`.** They are generated by `./init.sh codex` (or `.claude/tools/codex-sync/sync.sh`). Fix `.claude/` and regenerate (ADR-0021). Codex catalog IDs: edit `.claude/tools/codex-sync/models.json`, then regenerate (ADR-0022).
- **Never hand-edit `.cursor/` or `.grok/agents/`.** Same rule; regenerate with `./init.sh cursor` / `./init.sh grok`.
- Host-project facts belong in that host's `AGENTS.md` (Codex) or `CLAUDE.md` (Claude Code / Cursor). This file is only the harness's own Codex entry — it does not duplicate CLAUDE.md.

To refresh the Codex projection after changing skills or agents:

```bash
./init.sh codex .
```
