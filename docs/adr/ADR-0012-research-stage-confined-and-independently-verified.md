# ADR-0012 sonagi に調査工程を足す。非決定性は1工程に閉じ込め、事実は集めた本人が検証しない

## Context

当初 `sonagi` は「事実を調べない」設計だった。台本に載る事実は `brief.yaml` の `points:` に
人間が書いたものだけとし、誤情報を流さないための線としていた（[ADR-0009](ADR-0009-sonagi-stops-at-definitions.md)）。

この線は、動画の中身が「主張」であるテーマでは機能する。仕事術の検証では、
`points:` の4項目を人間が書けば台本が成立した。

しかし**動画の中身がまるごと事実であるテーマ**（雑学・解説）では前提が崩れる。
1本ごとに人間が全ての事実と出典を用意することになり、本数を回すと律速になる。
一方で、雑学は**1本の誤りでチャンネル全体の信用が消える**領域でもあり、
AI に調べさせてそのまま流すのは最も避けたい形である。

「調べない」と「調べて垂れ流す」の間に、成立する設計があるかが問題だった。

## Decision

**調査工程を足す。ただし非決定性を1工程に閉じ込め、事実は集めた本人に検証させない。**

- **外部を調べるのは `researcher` 1体だけ。** 台本を書く者も素材を作る者も、
  その出力 `research.md` の外に出ない。
- **`research.md` は書き終わった瞬間に凍る。** 以降のパイプラインはこれを固定入力として扱うので、
  **調査より下流は従来どおり「同じ入力 → 同じ出力構造」が成り立つ**。
  非決定的なのは調査工程だけであり、境界はファイルで切られる。
- **`fact-checker` が出典を開き直す。** 事実を1つも集めていない別コンテキストのオラクルが、
  URL を実際に開き、記述と突き合わせ、一次情報か・単一ソースでないか・古びていないかを見る。
  落とすべき主張と、下げるべき確度を返す。**採否は決めない**（人間の仕事）。
- **確度を3段階（`確実` / `おそらく` / `⚠要確認`）で必須にする。** 判断を人間に渡す唯一の手掛かりであり、
  台本はこの確度をナレーションの言い方に反映させる（`⚠要確認` を断定形で語らない）。
- **検証を人間ゲートより前に置く。** 落ちた事実の上に台本を建てさせないため、
  `fact-checker` の結果は `script-writer` の入力になる。人間は台本と事実を同じゲートで一度に見る。
- **`F-nnn` の参照切れは機械が撃つ**（`sonagi check` C17）。台本が参照する事実が `research.md` に
  実在するかは決定的に決まる。どのシーンが「事実を述べているか」は機械には見えないので、
  そちらは `fact-checker` と人間に委ねる。

ADR-0009 の「実体を生成しない」は変わらない。狭まったのは**入力側**であり、
出力側（画像・音声・動画を作らない）はそのままである。

## Consequences

- 事実が中身のテーマでも本数を回せるようになる。人間の仕事は「全部書く」から「判定する」に変わる。
- **「同じ入力 → 同じ出力」がパイプライン全体では言えなくなった。** 言えるのは `research.md` から下流だけである。
  評価の再現性もそこまでになる（調査工程を含む eval は不安定になる）。
- 1本あたりのエージェント起動が2体増え、外部リクエストと実行時間が増える。
- **誤情報のリスクはゼロにならない。** `fact-checker` が開けなかった出典、両論に出典がある論争、
  検証者自身の見落としは残る。設計が保証するのは「出典の無い断定が台本に入らないこと」であって、
  「事実が正しいこと」ではない。最終的な採否は人間が負う。

## 却下した選択肢

- **調べないまま（現状維持）**: 誤情報のリスクは最小だが、雑学のようなテーマでは
  1本ごとに人間が全事実を用意することになり、実運用の律速になる。
  ユーザーが本数を回す前提を示した時点で、この線は要求を満たさない。
- **researcher だけ足し、検証を置かない**: 実装は最も軽い。しかし集めた本人は自分が採った出典を信じており、
  自己検証は同じ思い込みを2度通すだけである。しかも下流に事実を見る者がいないので、
  **誤りがそのまま動画になる**。harness の核（作る主体 ≠ 判定する主体）にも反する。
- **調べた資料を人間が丸ごと渡し、script-writer が抜き出す**: 中間案。出典の管理は人間に残るので
  リスクは低いが、**確度の判定が誰の仕事でもなくなる**。資料に書いてあることの信頼性は
  資料ごとに違い、それを台本の言い方へ反映させる主体がいない。
- **検証を人間ゲートの後に置く**（台本を先に作り、あとで裏を取る）: ゲートが1つで済むが、
  落ちた事実の上に建てた台本を作り直すことになり、検証の結果を台本へ反映する往復が増える。
