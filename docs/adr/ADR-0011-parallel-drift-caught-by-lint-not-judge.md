# ADR-0011 並列生成が生む画風・境界のドリフトは、judge ではなく機械検査（C14–C16）で撃つ

## Context

`sonagi` の `asset-generator` はシーン単位で並列に走り、互いの出力を見ない。
このため**口調・用語・画風のブレは確率ではなく構造として必ず起きる**。書いた本人には自分の1シーンしか見えない。
当初はこれを丸ごと `judge`（素材を書いていない独立レビュアー）の担当にしていた。

評価を回した結果、judge は実際にこれらを摘発した。しかし摘発されたものの内訳を見ると、性質が2つに割れていた。

- **機械的に決まるもの**: `image.style` が `unbleached ecru` / `off-white` / `cream` / 欠落の4通りに割れる
  （実測では1本の動画で9通り）。シーン境界の `transition_out` と次の `transition_in` が食い違う。
  caption がナレーションの一部をそのまま写している。
- **機械には見えないもの**: 同じ比喩が複数シーンに出る。強調色の意味が動画の途中で反転する。
  台本の主張が `brief.yaml` の `points:` に根拠を持たない。

前者を judge に探させると、**毎回同じ探索に judge の文脈を使う**ことになる。しかも judge が正規形を名指しして
直させても、判定の根拠がどこにも残らないので**次回また割れる**（judge 自身がそう報告した）。

## Decision

**機械的に決まるドリフトは `tools/sonagi` に降ろす。**

| コード | 内容 |
| --- | --- |
| C14 | 全素材の `image.style` / `image.negative` が同一文字列か |
| C15 | シーン境界の `transition_out` ⇄ 次の `transition_in` の一致 |
| C16 | `channel/style.md` が `image.<key>` として**宣言した**正規文字列に全素材が一致するか |

併せて、`channel/style.md` の書式を**日本語の散文から「そのまま貼る英語の正規文字列（コードブロック）」へ変える**。
散文（「生成り」）で置くと producer が各自で英訳するため、割れの根が消えないからである。
何を固定するかはチャンネルの裁量とし、**宣言されたキーだけ**を強制する（`lighting` を場面ごとに変えたい構成もある）。

judge の観点表からはこの3項目を外し、機械に見えないもの（画のモチーフ重複・色の意味の反転・根拠のない主張）を足す。
judge の入力に `brief.yaml` を加える（主張の根拠を突き合わせられる主体が judge だけであるため）。

## Consequences

- 同じ欠陥を毎回 judge に探させる無駄が消え、judge の文脈が機械に見えないものへ向く。
  実測で judge の指摘の質が上がり、症状（色が反転している）ではなく根本原因
  （`style.md` に「間違い」を指す色が定義されていない）を挙げるようになった。
- 割れの判定根拠が `channel/style.md` という**残るファイル**に移り、次回も同じ基準が効く。
- **`channel/style.md` がフィールド名（`image.style`）を名指しする**ため、それを読む者にはスキーマが伝わる。
  評価上はベースラインが強くなり、スキルとの差分が小さく見える（改善の副作用であり、避けられない）。
- 表現の自由度が下がる。宣言したキーは全シーンで同一を強制されるので、
  「このシーンだけ光を変えたい」は宣言を外す判断とセットになる。

## 却下した選択肢

- **judge に任せ続ける**: 実際に摘発はできる。しかし毎回同じ探索にコストを払い、
  判定根拠が残らないので同じ割れが再発する。判定が LLM の注意力に依存するので、見落としも起きる。
- **`image.style` を全キー一律で固定する**: 割れは完全に消えるが、`lighting` や `composition` まで縛ると
  シーンごとの絵作りができなくなる。何を固定するかはチャンネルによって違う。
- **`asset-generator` を並列にしない**: ドリフトの根本原因を消せる唯一の案。
  しかし1脳で全シーンを書くと文脈が膨らみ、シーン数に比例して実行時間が伸びる。
  部分再実行（1シーンだけ作り直す）も成立しなくなる。並列の利得のほうが大きい。
