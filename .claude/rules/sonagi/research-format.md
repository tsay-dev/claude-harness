# 📦 調査の書式（research.md / research-review.md）

> 動画の中身がまるごと事実である場合（雑学・解説など）に、台本より前に置く工程の書式。
> なぜ調査を1工程に閉じ込めるかは [overview.md](overview.md)。
> 実行手続きは skill [sonagi](../../skills/sonagi/SKILL.md)。

## この工程が背負っているもの

**外部を調べるのは researcher 1体だけ**で、以降の工程は誰も調べない。
台本を書く者も素材を作る者も `research.md` の外に出ない。
だから**ここに入った誤りは、そのまま動画になる**。

そして `research.md` は、**書き終わった瞬間に凍る**。
以降のパイプラインはこのファイルを固定入力として扱うので、
調査より下流は今までどおり「同じ入力 → 同じ出力構造」が成り立つ。
**非決定性はこの1工程にだけ閉じ込める。**

## 🔒 確度は3段階（省略不可）

判断を人間に渡すための唯一の手掛かりなので、**全ての事実に付ける**。

| 確度 | 意味 |
| --- | --- |
| `確実` | 一次情報で裏が取れ、**独立した複数の出典**が一致する |
| `おそらく` | 出典はあるが単一、または一次情報まで辿れていない |
| `⚠要確認` | 広く流通しているが出所が怪しい／出典同士が食い違う |

**出典の無い事実は書かない。** 書けないものは、確度を下げるのではなく**落とす**。

## `research.md`（researcher が書く）

```markdown
---
video_id: <id>
topic: <調べた対象>
---

## F-01 <事実を1文で>

- **確度**: 確実
- **出典**: <URL または書誌>（<発行年>）
- **裏付け**: <出典の当該箇所の要約。原文の数字・単位・年をそのまま写す>
- **一次情報か**: はい / いいえ（<何を経由したか>）

## F-02 <事実を1文で>

- **確度**: ⚠要確認
- **出典**: <URL>（<年>）
- **裏付け**: <…>
- **一次情報か**: いいえ（まとめ記事どまり。原典に辿り着けず）
- **崩れどころ**: <どこが怪しいか>

## 辿れなかったもの

- <調べたが出典に行き着かなかった主張と、どこで行き止まったか>
```

- **`F-nnn` は台本から参照される識別子**である。欠番・重複を作らない。
- 数字は**単位と年を必ず併記**する。孫引きの過程で条件が落ちるのが最も多い崩れ方である。

## `research-review.md`（fact-checker が書く）

**出典を実際に開き直した結果**を書く。開けなかったなら「開けなかった」がそのまま結果であり、
記憶で埋めてはならない。

```markdown
## 落とすべき（出典が存在しない／そう言っていない）
- **F-03** — 出典 URL が 404。別の出典も見つからない

## 確度を下げるべき
- **F-01** `確実` → `おそらく` — 独立した2つ目の出典が見つからない

## 妥当（開いて突き合わせた）
- **F-02** — 出典を開き、記述と一致することを確認（<開いた URL>）

## ⚠ 人間判断
- **F-05** — 通説と、その否定と、否定への反論がいずれも出典を持つ。どれを採るか
```

## 台本との接続

`script.md` の各シーンが**どの `F-nnn` に依拠しているか**を書けるようにする。
どこにも依拠しないシーン（導入・つなぎ・CTA）は空でよいが、
**事実を述べているのに `F-nnn` が無いシーンは、出典の無い断定である**。
